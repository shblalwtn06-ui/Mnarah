# المنارة الذكي v3.3.1 — تقرير المراجعة النهائية

## نطاق الجولة
تمت مراجعة النسخة v3.3 على مستوى:
- Frontend JavaScript وHTML/CSS.
- Backend routes.
- ربط API بين الواجهة والخادم.
- PostgreSQL schema والفهارس الخاصة بالبحث.
- البحث العربي وتطبيع الحروف والمرادفات اليمنية.
- نقاط الأعطال المؤكدة في الجولة السابقة.

## إصلاحات هذه الجولة

### 1. البحث الذكي العربي/اليمني
- إضافة `search_name` مفهرس بـ `GIN + pg_trgm`.
- إضافة تطبيع عربي للحروف: أ/إ/آ/ٱ → ا، ى → ي، ة → ه، وغيرها.
- إضافة `search_synonyms` للمرادفات المحلية.
- إضافة `product_search_aliases` لمرادفات كل منتج.
- البحث يجمع بين الاسم والباركود والمرادف والتشابه النصي.
- إصلاح استعلام `DISTINCT + ORDER BY similarity` السابق.
- زر البحث الذكي في واجهة المنتجات أصبح مربوطًا مباشرة بـ `/api/products/search-advanced`.

### 2. تعديل المنتجات
- إصلاح مشكلة تحديث الأسعار التي كانت قد تستخدم Defaults عند عدم إرسال الحقل.
- أصبح تحديث المنتج جزئيًا: الحقول غير المرسلة تحتفظ بقيمها الحالية.
- نموذج التعديل أصبح يعرض سعر البيع والجملة وحد الجملة ومرادفات البحث.

### 3. تفاصيل المنتج
- إضافة مرادفات المنتج إلى استجابة `GET /api/products/:id` حتى تستطيع الواجهة إعادة تحريرها.

### 4. Dashboard
- تثبيت استخدام Chart.js بدل الاعتماد على رسم Canvas مخصص.
- إضافة Drill-down لمبيعات اليوم وأرباح اليوم بدل رسالة عدم توفر التفاصيل.
- الحفاظ على Escape للبيانات المعروضة.

### 5. الإعدادات
- إصلاح حفظ الإعدادات ليستخدم `await` و`try/catch`.
- لا تظهر رسالة نجاح إذا فشل API.

### 6. الفحص
- فحص Syntax لجميع ملفات JavaScript: ناجح.
- فحص إضافي للملفات التي تم تعديلها: ناجح.
- تم إنشاء الحزمة النهائية واختبار سلامة الضغط.

## ملاحظة اختبار مهمة
اختبار PostgreSQL End-to-End يحتاج خادم PostgreSQL فعليًا وبيانات اتصال `.env`. بيئة المراجعة الحالية لا تحتوي خادم PostgreSQL متاحًا للاختبار الحي؛ لذلك لا يتم الادعاء بأن اختبارات قاعدة البيانات الحية تمت.

## البحث اليمني
البحث أصبح يدعم طبقة مرادفات قابلة للتوسعة، وليس مجرد `pg_trgm`. المرادفات الحالية تشمل أمثلة محلية مثل: مويه/ميه/موية، بطاطا/بطاطس، طماطه/طماطم، بسباس/فلفل. ويمكن إضافة مرادفات المتجر من خلال `product_search_aliases`.

## حالة الإصدار
هذه النسخة هي النسخة المرشحة للاختبار التشغيلي النهائي على PostgreSQL الحقيقي قبل الإنتاج.
