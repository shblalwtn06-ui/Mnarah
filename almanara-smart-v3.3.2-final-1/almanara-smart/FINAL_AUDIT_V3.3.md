# تقرير المراجعة النهائية — المنارة الذكي v3.3

## النطاق
تمت مراجعة بنية Frontend وBackend وقاعدة البيانات، مع إضافة وحدات v3.3 المطلوبة.

## الوحدات النهائية
- POS: بحث، سلة، دفع 2×2، باركود HID، كاميرا، Offline queue، عملات.
- Dashboard: KPI وDrill-down وChart.js وتنبيهات المخزون والصلاحية والديون والمزامنة.
- المنتجات: CRUD، وحدات، باركود، مخزون افتتاحي، دفعات، تصدير وطباعة.
- العملاء: CRUD، تفاصيل، تسديد دين.
- الموردون: CRUD، استلام، أوامر شراء.
- المشتريات: أوامر شراء وبنود وضريبة.
- المخزون: عرض، تسوية، حركات، دفعات.
- الفواتير والمرتجعات: عرض، تفاصيل، إلغاء، واجهة المرتجعات.
- التقارير: مبيعات، أرباح، مخزون، ديون العملاء، ديون الموردين، ورديات، وسائل دفع، أفضل المنتجات، تصنيفات.
- الورديات: فتح، إغلاق، قائمة وملخص.
- المصروفات: إنشاء وعرض وتصدير وطباعة وربط محاسبي.
- وسائل الدفع: CRUD.
- المحاسبة: الحسابات، القيود، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية العمومية.
- الخرج اليومي: سحب/إيداع مع قيد محاسبي وتقرير الوردية.
- الضرائب: جدول ومعدل وإسناد للحساب وإظهارها في البيع/الشراء.
- العملات: YER/SAR/USD وسجل أسعار صرف وتسجيل العملة وسعر الصرف على الفاتورة.
- الأمان: JWT، Argon2id، RBAC، Rate limiting، Helmet/CSP، معاملات PostgreSQL.
- Offline: Service Worker + IndexedDB للمنتجات والفواتير والورديات وطابور المبيعات.

## قيود مهمة
- اختبار JavaScript تم محليًا عبر `npm test`.
- اختبار PostgreSQL التكاملـي يتطلب تشغيل PostgreSQL فعليًا؛ ملف Docker Compose مرفق لذلك.
- مكتبتا Chart.js وhtml5-qrcode محملتان من CDN عند الاتصال؛ تشغيل الكاميرا دون شبكة يحتاج تثبيت نسخة محلية من المكتبة أو تضمينها في App Shell.
- أسعار الصرف مخزنة `NUMERIC(12,2)` وفق القاعدة الإلزامية؛ إذا احتاج النشاط دقة صرف أعلى، ينبغي تعديل القيد إلى دقة أكبر كقرار محاسبي منفصل.
